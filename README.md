# Flowdesk — Project Management Dashboard

Flowdesk — современное веб-приложение для управления задачами и проектами. Интерфейс выполнен в минималистичном тёмном стиле с акцентными цветами, плавными анимациями и адаптивной вёрсткой.

## ✨ Возможности

- 📊 Dashboard с общей статистикой и продуктивностью.
- ✅ Создание, удаление и выполнение задач.
- 🔎 Поиск задач по названию и проекту.
- 🎯 Фильтрация задач по статусу.
- 📁 Управление проектами и отслеживание прогресса.
- 📈 Интерактивная аналитика с графиками.
- 🌙 Переключение между тёмной и светлой темами.
- 🔔 Панель уведомлений.
- 💾 Автоматическое сохранение задач в LocalStorage.
- 📱 Адаптивный интерфейс для мобильных устройств.
- ✨ Плавные анимации и интерактивные элементы.

## 🛠 Технологии

- React 18
- TypeScript
- Vite
- Recharts
- Lucide React
- CSS3
- LocalStorage API

## 🚀 Запуск проекта

Клонируйте репозиторий:

```bash
git clone https://github.com/YOUR_USERNAME/flowdesk.git
```

Перейдите в папку проекта:

```bash
cd flowdesk
```

Установите зависимости:

```bash
npm install
```

Запустите локальный сервер:

```bash
npm run dev
```

Для production-сборки:

```bash
npm run build
```

## 💡 Хранение данных

На текущем этапе задачи сохраняются в LocalStorage браузера. Backend и серверная база данных пока не подключены.
